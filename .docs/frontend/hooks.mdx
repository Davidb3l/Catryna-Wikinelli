# React Hooks

Custom React hooks for data fetching and state management.

## useDocsList

Fetches the list of all documents and builds a navigation tree.

```typescript
const { 
  docs,      // DocMetadata[] - flat list of all docs
  navItems,  // NavItem[] - hierarchical nav tree
  loading,   // boolean
  error,     // string | null
  refetch    // () => Promise<void>
} = useDocsList();
```

Automatically fetches on mount from `/api/docs`. The `navItems` are built by `buildNavTree()`, which groups docs by path folders.

The tree is only **one level deep**, despite `NavItem.children` being recursive. `buildNavTree()` keys folders by the doc's full folder path but titles them with the last segment and pushes every folder onto the root array — so `a/b/c` renders as a top-level folder named `b`, not nested under `a`.

## useDoc

Fetches a single document by path.

```typescript
const { 
  doc,       // Document | null
  loading,   // boolean
  error,     // string | null
  refetch    // () => Promise<Document | null> | null | ''
} = useDoc(path);  // path: string | null
```

When `path` is null, returns null without fetching. On 404, sets doc to null without error.

`refetch` is written as `() => path && fetchDoc(path)`, so it returns the falsy `path` rather than a promise when nothing is selected — always guard before awaiting it.

The API response is mapped by `toDocument()`: `path` is split on `/` into a string array, `lastUpdated` is `new Date(updatedAt).toISOString()`, and `history` / `isDraft` are never populated.

## useDocsSearch

Search across all documents.

```typescript
const { 
  results,   // DocMetadata[]
  loading,   // boolean
  error,     // string | null
  search     // (query: string) => Promise<DocMetadata[]>
} = useDocsSearch();
```

The `search` function requires a minimum of 2 characters (shorter queries clear the results and return `[]` without a request). Calls `/api/docs/search?q={query}`.

Despite the name, this is not full-text search: the endpoint matches every whitespace-separated term against the doc's **title, tags, and path** from `_index.json` and caps results at 20. Body content is never searched.

## EMPTY_DOC

Default placeholder document shown when no doc is selected:

```typescript
export const EMPTY_DOC: Document = {
  id: 'empty',
  title: 'No Document Selected',
  path: [],
  blocks: [
    { id: 'empty-1', type: 'heading-1', content: 'Welcome to Catryna Wikinelli' },
    { id: 'empty-2', type: 'paragraph', content: 'Select a document from the sidebar...' },
    { id: 'empty-3', type: 'callout', content: 'Use MCP tools to create docs.', metadata: { level: 'info' } },
  ],
  lastUpdated: new Date().toISOString(),
};
```
