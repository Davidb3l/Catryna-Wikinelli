# Gemini AI Service

Optional AI-powered features using Google's Gemini API for intelligent documentation assistance.

## Overview

Located at `frontend/services/geminiService.ts`, this service provides AI-powered utilities for documentation generation. It calls the Google Gemini API **directly from the browser** via `@google/genai`, using the `gemini-3-flash-preview` model.

<Callout type="warning">
Nothing calls it. `App.tsx` imports `geminiService` and never invokes either method — there is no UI entry point for these features today. Treat this page as a description of dormant code, not of shipped behaviour.
</Callout>

## Methods

### summarizeCode

Generates a concise technical summary of code for documentation.

```typescript
await geminiService.summarizeCode(codeString);
// Returns: string - Technical summary
```

### suggestDocumentStructure

Suggests headings for a technical document on a given topic.

```typescript
await geminiService.suggestDocumentStructure("authentication");
// Returns: string[] - e.g., ["Overview", "Installation", "API Usage", "Examples"]
```

## Configuration

Both methods read `process.env.API_KEY`. That is not a runtime environment variable in the browser — `frontend/vite.config.ts` uses Vite's `define` to substitute it at build time:

```typescript
define: {
  'process.env.API_KEY': JSON.stringify(env.GEMINI_API_KEY),
  'process.env.GEMINI_API_KEY': JSON.stringify(env.GEMINI_API_KEY)
}
```

So the key you put in `GEMINI_API_KEY` is read from the environment at build/dev-server startup and **inlined as a string literal into the client bundle**.

<Callout type="warning">
This means a client-side API key: any user who can load the viewer can read the key out of the served JavaScript, and every request goes browser → Google with no server in between. Fine for a `localhost`-only docs viewer with a throwaway key; do not host the built viewer anywhere reachable with a key you care about. If these features are ever wired up for real, the call belongs behind a server route (the `docs-api` plugin) rather than in the bundle. Leaving `GEMINI_API_KEY` unset is the safe default — nothing in the viewer needs it.
</Callout>

<Callout type="info">
This service is optional and entirely frontend-side. The MCP tools and the `catryna` CLI work independently and never touch Gemini.
</Callout>
